# Політика приватності Znimok

> Чернетка (28.09.2026, ZK-84) — набирає чинності з першим публічним релізом після рецензії власником.
> English: [privacy.en.md](privacy.en.md).

**Коротко:** Znimok працює на вашому комп'ютері. Він не збирає телеметрії, статистики чи аналітики, не
показує реклами й нікуди нічого не надсилає без вашої дії. Єдиний мережевий запит, який програма робить
сама, — перевірка оновлень, і його можна вимкнути.

## Що обробляє Znimok

- **Знімки й записи екрана**, які ви робите, і все, що ви на них додаєте: позначки, назви, описи, теги.
- **Відомості про джерело**: назва вікна й програми, розмір і номер монітора, дата зйомки — щоб бібліотека
  могла їх показати й шукати.
- **Розпізнаний текст** на знімках (OCR), якщо ви ввімкнули пошук за текстом. Розпізнавання працює на
  пристрої.
- **Налаштування** програми.
- **Журнал дій** AI-агентів і помічника: час, команда, чи був знімок, кількість токенів і оцінка вартості —
  **без зображень**; зберігається 90 днів.
- Під час запису відео (v2), лише якщо ви це ввімкнули: звук системи й мікрофона, рух курсора й кліки,
  лог DevTools із браузера через розширення Znimok.

## Де це зберігається

Усе — на вашому пристрої:

| Дані | Місце |
|---|---|
| Бібліотека (знімки, відео, звіти) | тека, яку ви вибрали; типово `%LOCALAPPDATA%\Znimok\Library` (Windows), `~/Library/Application Support/Znimok/Library` (macOS) |
| Індекс бібліотеки й мініатюри | тека кешу програми |
| Налаштування, журнал дій, ключі агентів | тека конфігурації програми |
| Ключ API хмарної моделі | системне сховище: Windows Credential Manager / macOS Keychain |
| Звіти про збої | локальна тека програми |

Якщо ви поклали теку бібліотеки на хмарний диск (OneDrive, iCloud Drive, Google Drive, NAS), файли
синхронізує цей сервіс за його правилами. Znimok сам нічого туди не відправляє.

## Коли дані залишають пристрій

Лише в таких випадках:

1. **Перевірка оновлень** (можна вимкнути в Налаштування → Приватність). Znimok звертається до GitHub
   Releases, щоб дізнатися номер останньої версії, і завантажує оновлення, якщо ви його встановлюєте.
   GitHub бачить вашу IP-адресу й сам запит — як при відкритті будь-якої сторінки. Жодних даних про вас
   чи ваші знімки не передається.
2. **Ви самі ділитеся результатом**: копіюєте в буфер, зберігаєте файл, використовуєте системне меню
   «Поділитися» чи (згодом) інтеграції зі Slack, Jira, Telegram, Redmine. Куди і що піде, вирішуєте ви.
3. **Хмарна модель з вашим ключем** (помічник Ctrl+K та інші функції, які ви ввімкнули). Без ключа хмара
   недоступна. З ключем:
   - без окремого питання йде лише текст вашої команди й структура документа без пікселів (позначки,
     розміри, назва, теги);
   - зображення — лише якщо команда його потребує, після маскування на пристрої і діалогу «Надіслати
     знімок?» з попереднім переглядом саме того, що буде надіслано;
   - дані обробляє провайдер моделі (Anthropic) відповідно до його політики і вашого з ним договору; Znimok
     не має до них доступу;
   - перед першою хмарною дією Znimok пояснює, що платно і скільки приблизно коштує.
4. **AI-агенти на вашому комп'ютері** (Claude Code, Claude Desktop та інші через MCP). Доступ вимкнено,
   доки ви його не ввімкнете. Кожен агент отримує дані лише в межах дозволів, які ви дали («лише зараз»,
   «цю сесію», «завжди»); під час знімка видно жовтий індикатор, а кожна дія записується в журнал.
   Що агент робить з отриманими даними далі, визначають його розробник і ваші налаштування цього агента.
5. **Звіт про збій** надсилаєте лише ви: програма зберігає його локально й може запропонувати відкрити
   сторінку issue на GitHub. Що прикласти, вирішуєте ви.

## Чого Znimok не робить

- не збирає телеметрії, статистики використання, аналітики, ідентифікаторів пристрою — і не має для цього
  перемикача, бо нема чого вмикати;
- не показує реклами й не продає та не передає даних третім особам;
- не перехоплює клавіатуру: гарячі клавіші реєструються засобами ОС, без глобальних хуків;
- не записує екран чи звук приховано: запис завжди видно (рамка, стан у треї, плашка).

## Метадані у файлах, якими ви ділитеся

Під час експорту Znimok може записати у файл назву, опис, автора й дату (ви бачите це в діалозі експорту).
Назва вікна, програма й шляхи до файлів у файли для поширення не записуються. Опція «Прибрати всі
метадані» видаляє все, крім технічно необхідного.

## Ваш контроль

- Вимкнути перевірку оновлень, хмарні функції, доступ агентів — у Налаштуваннях.
- Відкликати дозволи агентів — сторінка «Агенти» → «Відкликати всі дозволи».
- Видалити ключ API — Налаштування → Приватність.
- Видалити знімки — у бібліотеці (у кошик ОС) або просто видалити файли в теці бібліотеки.
- Видалити все — видалити програму, теку бібліотеки, теки кешу й конфігурації; ключ — у системному
  сховищі облікових даних.
