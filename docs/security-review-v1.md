## Обсяг

Місця, де Znimok розбирає дані, які могли прийти ззовні, або дає іншому процесу щось робити:

| Точка входу | Хто може подати дані | Код |
|---|---|---|
| Файл `.znimok` (відкриття, бібліотека, мініатюри) | будь-хто, хто дасть файл | `znimok-format`, `znimok-thumbnail` |
| Буфер обміну | будь-яка програма користувача | `znimok-win`/`znimok-mac` `clipboard` |
| IPC до застосунку | процеси того самого користувача з токеном | `znimok-ipc` |
| MCP (`znimok mcp`) | агент, якого запустив користувач | `znimok-agents` |
| Помічник Ctrl+K | модель (відповіді хмари) | `znimok-assistant` |
| «Передати агенту» | текст з екрана в командний рядок | `znimok-agents::handoff` |
| Обробник мініатюр | Провідник / Finder на будь-якому `.znimok` | `znimok-thumbnail` |
| Реліз і оновлення | GitHub, мережа | `release.yml`, `verify_release.py` |

## Знахідки

| # | Де | Що | Серйозність | Стан |
|---|---|---|---|---|

## Що перевірено й тримається

- **Формат:** усі блоки з межами (`Limits`: розмір файлу, рядків, об'єктів, точок, банків; PNG пікселів — від заголовка до виділення пам'яті); fuzz-ціль `read` (ZK-27) з регресіями.
- **IPC:** DACL лише користувач / сокет 0600 у теці 0700; токен сесії з порівнянням за сталий час; ліміти розміру, часу, клієнтів, частоти; перевірка чужим обліковим записом у CI на обох ОС (ZK-31, ZK-112).
- **MCP:** вимкнено за замовчуванням; дозвіл на область і клієнта; журнал без вмісту; без мережі.
- **Помічник:** модель не виконує нічого сама — план, пробне застосування на копії, підтвердження експорту/копіювання; пікселі лише після згоди й маскування.
- **Передача агенту:** текст з екрана ніколи не йде в рядок команди; шлях перевіряється на `%` і `"` (cmd), лапки для POSIX-оболонки й AppleScript перевірені тестами; копія з прихованими секретами за замовчуванням.
- **HTML-експорт:** CSP `default-src 'none'`, увесь текст екранований, оригінал без маскування не вкладається.
- **Секрети:** ключ API лише в Credential Manager / Keychain; у налаштуваннях і журналах — ніколи.
- **Мініатюри:** читається лише голова файла (≤64 МБ) до `THMB`, пікселі документа — ніколи; обробник у Windows працює в ізольованому процесі оболонки; розширення Quick Look — у пісочниці.
- **Ланцюг постачання:** cargo-deny (ліцензії, джерела), cargo-audit щотижня, cargo-vet, SBOM, `cargo auditable` у релізних бінарниках; HTTP і TLS — стек ОС, без власного TLS.

## Вимоги до оновлювача (ZK-78 / ZK-111), щоб не з'явилось S8

1. Перевірка лише за розкладом, якщо користувач увімкнув (`updates.check_daily`, типово вимкнено).
2. Джерело — лише `github.com/V-Plum/znimok` releases по HTTPS через стек ОС.
3. Завантажений `SHA256SUMS` перевіряється **підписом ECDSA P-256** вбудованим публічним ключем **до** будь-якої дії з інсталятором; потім SHA-256 самого `.msi` / `.zip`.
4. Без відкату версії (нова версія > поточної), без запуску з тимчасової теки, доступної іншим.
5. На Windows — `msiexec /i … /qn` для одного користувача після виходу застосунку; на macOS — Sparkle (EdDSA) з нашим вікном.
6. Ротація ключа — релізом, підписаним старим ключем (як у Little Helpers).

## Наступний прохід

- Fuzz буфера обміну (DIB/PNG) і `peek` з мініатюрою — додати цілі поруч із `read`.
- Після появи оновлювача — окремий огляд його коду.
- Перевірити S7 після виправлення в застосунку.
