# Znimok keys

Every shortcut of the prototype (ZK-60). On macOS, ⌘ stands in for Ctrl and Shift is shown as ⇧.
Tooltips in the app write shortcuts the way the current system does. Tool letters also work on the
Ukrainian layout (V/м, R/к, E/у, L/д and so on).

## Capture

| Action | Windows | macOS |
|---|---|---|
| New screenshot: freeze the screen under the pointer | Ctrl+Shift+4 | ⌃⇧4 |
| Region | drag | drag |
| Window | click | click |
| Whole screen | Space | Space |
| Straight to the clipboard and the library, no editor | Shift on release | ⇧ on release |
| Loupe zoom | wheel | wheel or trackpad |
| Cancel | Esc | Esc |

## Esc

Esc takes off exactly one layer at a time:

1. a drag in progress;
2. the crop being edited;
3. the selection;
4. the tool (back to Select);
5. the document — back to the library.

If autosave is off and there are unsaved changes, Znimok asks first whether to save them.

In dialogs, Enter is the main button and Esc is Cancel.
