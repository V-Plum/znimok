# Клавіші Znimok

Таблиця всіх скорочень прототипу (ZK-60). На macOS замість Ctrl — ⌘, а Shift показано як ⇧.
Підказки в застосунку пишуть скорочення так, як заведено в поточній системі. Літери інструментів
працюють і в українській розкладці: V/м, R/к, E/у, L/д і так далі.

## Знімок

| Дія | Windows | macOS |
|---|---|---|
| Новий знімок: заморозити екран під курсором | Alt+Shift+4 | ⌃⇧4 |
| Ділянка | потягнути | потягнути |
| Вікно | клацнути | клацнути |
| Весь екран | Space | Space |
| Відкрити в редакторі | відпустити | відпустити |
| Одразу в буфер і бібліотеку, без редактора | Shift під час відпускання | ⇧ під час відпускання |
| Правити просто поверх екрана | Alt під час відпускання | ⌥ під час відпускання |
| Знімок через 3 секунди | подвійний клік або клік і одразу тягнути | так само |
| Знімок із прокруткою | S | S |
| Зчитати QR-коди й штрихкоди | Q | Q |
| Збільшення лупи | коліщатко | коліщатко або трекпад |
| Скасувати | Esc | Esc |

Важить лише те, які клавіші затиснуті в мить відпускання кнопки миші, — не важливо, натиснули їх
до кліку чи після. Що робить кожен жест (відпустити / Shift / Alt), можна переназначити в
Налаштування → Знімки; смуга підказок унизу накладки показує поточні призначення (її теж можна
вимкнути там само).

## Esc

Esc знімає рівно один шар за раз:

1. перетягування, що триває;
2. кадр, якщо він редагується;
3. вибір;
4. інструмент (повертається «Вибір»);
5. документ — повернення в бібліотеку.

Якщо автозбереження вимкнене й є незбережені зміни, Znimok спершу спитає, чи зберегти їх.

У діалогах Enter — основна кнопка, Esc — «Скасувати».
