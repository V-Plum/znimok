## 2. Уточнення — ВІДПОВІДІ власника (28.09.2026, вже в макеті v17 і в `decisions.md`)

1. **Збереження:** тогл «Зберігати автоматично» у заголовку редактора (глобальний, типово увімкнено). Вимкнено → явний Ctrl+S, індикатор «незбережено» + «Зберегти», питання при закритті.
2. **Головна кнопка ряду дій — «Копіювати»** (клік = зображення в буфер), стрілка «Інші способи» (як файл, системне «Поділитися», експорт, HTML, агент, цілі). Windows: кожна копія — окремий запис Win+V (PNG + CF_DIB, без CF_BITMAP). Відео копіює файл. Той самий підпис усюди — «Експорт» як назва кнопки не використовується.
3. **macOS клавіші:** запас ⌃⇧3/4/5; онбординг пропонує вимкнути системні ⌘⇧3/4/5 у Системних налаштуваннях, після чого Znimok реєструє їх сам (перевірка при старті й після повернення з налаштувань).
4. **Розумні напрямні** (центри, краї, рівні відстані) у v1, вимикач у налаштуваннях.
5. **Трей:** лівий і правий клік — одне меню; опція «лівий клік = Новий знімок».
6. **Тека бібліотеки:** крок онбордингу з типовим шляхом і «Змінити…» (перенесення файлів при зміні — з налаштувань).
7. **Помічник Ctrl+K — вирішено 28.09:** Sonnet 5 типово / Opus 5.5 у налаштуваннях; в хмару без питання — лише текст команди + структура без пікселів; знімок — після локального маскування через діалог «Надіслати знімок?» (прев'ю, «не питати для цього документа», «не питати більше»); перша хмарна дія — пояснення вартості замість ліміту; ключ у Credential Manager/Keychain; дії — правки документа (undo) + експорт/копіювання з підтвердженням; без ключа — локальна командна палітра; журнал 90 днів без зображень у «Агентах». Деталі — `decisions.md` [2026-09-28].
8. Емодзі — системний шрифт. 9. Плашка — на моніторі знімка. 10. Undo — орієнтир 500 кроків, обмеження пам'яттю. 11. Відлік — подвійний клік. 12. Остання вкладка → бібліотека з «Новий знімок». 13. Англійську рецензує Fable. 14. «Znimok» без перекладу. 15. Посилання — пізніше.
16. **«Відкрити ▾»** у заголовку (Файл… Ctrl+O, З буфера обміну, Новий знімок ▸, Порожнє полотно) і «Відкрити…» на домашньому екрані.
17. **Windows-first**, інсталятор `.msi` (WiX, per-user, major upgrade) — див. `decisions.md` [2026-09-28] і PLAN §4/§7.
