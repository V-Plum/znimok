# Заморозка й видалення знімків і відео в Little Helpers (ZK-82)

Функції знімків і відео переїжджають з Little Helpers (LH) у Znimok. За рішенням власника
(PLAN, рішення 29) — **чистий аркуш**: переносимо функціонал, не файли; імпортерів `.lhshot`,
`.lhvideo`, `.lhreport` і міграції налаштувань не буде. Цей план — як пройти шлях так, щоб
користувач LH ніде не лишився без інструмента, не отримав двох програм, що б'ються за одні клавіші,
і не втратив своїх знімків.

## Що є в LH зараз (4.14.0)

| Частина | Znimok, де з'являється |
|---|---|
| Гарячі клавіші знімків: Ctrl+Alt+4, Alt+Shift+4, Alt+Shift+3, Ctrl+Alt+E | v1.0 (ті самі типові клавіші — ZK-28) |
| Накладка вибору, редактор знімків, позначки, бібліотека `.lhshot` | v1.0 |
| Запис відео Alt+Shift+5, редактор відео, `.lhvideo`, MP4/GIF | **v2.0** (Фаза 8) |
| Звіт для розробника `.lhreport`, лог DevTools, розширення браузера | **v2.0** (ZK-97, ZK-98) |
| Розкладка, курсор, день/ніч, перегляд по пробілу | лишаються в LH |

Головне: **Znimok v1.0 не має відео.** Тому знімки й відео йдуть з LH у різний час.

## Проблема, яку треба закрити першою: однакові клавіші

Znimok навмисно взяв типові клавіші LH. Якщо обидві програми запущені, `RegisterHotKey` отримає
та, що стартувала першою; друга мовчки лишиться без клавіш. Тому співіснування — окремий крок,
раніше за видалення.

## Етапи

### Етап 0 — заморозка (з дати рішення)
- LH: **жодних нових функцій** знімків і відео; лише виправлення помилок. Нові ідеї для знімків і
  відео — тікети в ZK, не в CAPS.
- README LH: абзац «Знімки й відео переїжджають у Znimok» (uk/en — правило README обома мовами).

### Етап 1 — співіснування (реліз LH разом із Znimok 1.0)
- **LH бачить Znimok** (розширення `.znimok` зареєстроване на `Znimok.Document` у
  `HKCU\Software\Classes`, або встановлений MSI) → у налаштуваннях і один раз сповіщенням: «Знімки
  тепер у Znimok. Віддати йому клавіші знімків?» → `CaptureEnabled = 0` (клавіші звільняються
  одразу, як і зараз при вимкненні). **Відео в LH лишається** — Znimok v1 його не вміє.
- **Znimok бачить LH** (процес або `HKCU\Software\lilhelpers\CaptureEnabled = 1`) → у провіднику
  першого запуску: «Little Helpers теж знімає екран цими клавішами: [Вимкнути знімки в Little
  Helpers] / [Інші клавіші для Znimok]». Перший варіант пише `CaptureEnabled = 0` і надсилає LH
  зареєстроване повідомлення `lilhelpers-reload-capture` (LH перечитує налаштування без
  перезапуску — треба додати в LH).
- Znimok v1 **не реєструє клавішу відео** (Alt+Shift+5) — вона лишається за LH до Znimok 2.0.
- LH: пункт «Експортувати всю бібліотеку…» — усі знімки в PNG з позначками (і відео в MP4) у
  вибрану теку, з тими самими назвами й датами. Це замість імпортера в Znimok.

### Етап 2 — видалення знімків з LH (≈ 3 місяці після Znimok 1.0, або 2 релізи LH)
- За реліз до видалення — попередження в LH: «У наступній версії знімки зникнуть; експортуйте
  бібліотеку». Кнопка експорту — поруч.
- Видаляються: клавіші й накладка знімків, редактор знімків, `.lhshot` у бібліотеці. Бібліотека
  лишається для відео.
- Налаштування `Cap*`, `Lib*` (для знімків), `Editor*`, `OverlayEscSave` — видаляються з реєстру
  при першому запуску нової версії.

### Етап 3 — відео (Znimok 2.0)
- Той самий шлях: співіснування (клавіша Alt+Shift+5 → Znimok), експорт бібліотеки відео,
  видалення через ≈ 3 місяці: запис, редактор відео, GIF, звіт, лог DevTools, розширення браузера
  (переходить у Znimok через Native Messaging, ZK-97).

### Етап 4 — LH знову маленький
Розкладка, курсор, день/ніч, перегляд. Менший exe — менше хибних спрацювань антивірусів
(Wacatac на великих exe з захопленням екрана й клавіатурними хуками).

## Рішення власника (потрібні до старту етапу 0)

1. **Дата заморозки** нових функцій знімків/відео в LH: пропоную — з сьогодні (29.09.2026).
2. **Скільки тримати знімки в LH після Znimok 1.0:** пропоную 3 місяці або 2 релізи LH — що довше.
3. **Хто передає клавіші:** пропоную обидва напрямки (LH бачить Znimok і Znimok бачить LH), бо
   встановлюють їх у будь-якому порядку.
4. **Бібліотека LH перед видаленням:** пропоную лише пакетний експорт у PNG/MP4 (без імпортера в
   Znimok — за рішенням 29); альтернатива — лишити в LH переглядач бібліотеки лише для читання.
