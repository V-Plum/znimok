# Znimok

**Українська** · [English](README.en.md)

> **У розробці.** Готових збірок ще немає; код і план змінюються.

Знімки й запис екрана для Windows і macOS з редактором, у якому позначки лишаються
редагованими: стрілку, напис чи приховану ділянку можна поправити й через тиждень.
Знімки й записи лежать у бібліотеці у власному відкритому форматі; результат іде в
буфер обміну, у файл або одразу людині чи агенту.

Znimok — наступник функцій знімків і відео з
[Little Helpers](https://github.com/V-Plum/lilhelpers): той самий досвід, але новий код
на Rust, дві ОС, інсталятор і сучасний інтерфейс. Сумісності з файлами Little Helpers
немає — переноситься функціонал, а не формат.

## Що буде в першій версії

- Знімок екрана, вікна чи ділянки з правильною експозицією в HDR.
- Редактор: рамки, стрілки, текст, лічильники, штампи, маркер, приховування (плашка,
  пікселі, розмиття), кадрування, ефекти; скасування будь-якої дії.
- Бібліотека з мініатюрами, метаданими й пошуком.
- Експорт у PNG/JPEG і поширення; шар команд, CLI і MCP для агентів.

Запис відео з синхронним логом DevTools — у другій версії. Повний план —
[docs/PLAN.md](docs/PLAN.md).

## Спробувати прототип

Перший робочий прототип застосунку — крейт `znimok-app`. Він уміє бібліотеку з мініатюрами й
пошуком, редактор із десятьма інструментами, скасування, автозбереження в бібліотеку,
«Копіювати», експорт у PNG/JPEG/WebP, відкриття файлу, вставку з буфера й перетягування
зображення у вікно. «Новий знімок», Ctrl+Shift+4 (Windows) або ⌃⇧4 (macOS) заморожують
екран під курсором: потягніть — ділянка, клацніть — вікно, Space — весь екран, Shift при
відпусканні — одразу в буфер і бібліотеку, Esc — скасувати. Znimok живе в треї / смузі меню;
закриття вікна ховає його туди, «Вийти» — в меню значка. Виділення: рамка по порожньому,
Shift/Ctrl-клік, затиснутий Ctrl — тимчасово «Вибір»; Ctrl+D дублює, Ctrl+]/[ міняє порядок,
Ctrl+G групує; вирівнювання й розподіл — в інспекторі.

Лінія (L) з наконечниками на будь-якому кінці — вони ж є й в олівця; для лінії в інспекторі
X1/Y1/X2/Y2, для фігур, тексту, кружечків і штампів — тінь і свічення. Вкладка «Знімок»:
кадр (C — уся картинка на екрані, протягніть рамку, тягніть ручки чи середину; Enter —
застосувати, Esc — скасувати), поворот і дзеркала, тон (експозиція, гамма, контраст;
утримуйте «Порівняти», щоб побачити оригінал) і розмір зображення. Кадр, поворот і тон —
рецепт поверх оригіналу, кожна зміна скасовується одним кроком. Кнопку «Копіювати» можна
потягнути в чат чи теку — піде PNG-файл. Питання (наприклад, «Зберегти зміни?» при
вимкненому автозбереженні) Znimok ставить у власному вікні, не системному.

Курсор підказує, що станеться: стрілка без хвоста інструмента «Вибір», чотирибічна стрілка над
позначкою, стрілки зміни розміру на ручках, приціл для малювання й кадру, «рука» над кнопками й
повзунками. Шари перетягуються: рядок між іншими — новий порядок, на інший рядок — група; групи
згортаються, око ховає всю групу. Esc знімає по одному шару (перетягування, кадр, вибір,
інструмент, далі — бібліотека), Enter повторює останню дію (копіювати чи експорт), `[`/`]` —
товщина, Ctrl+=/− — масштаб. Уся таблиця клавіш — [docs/SHORTCUTS.md](docs/SHORTCUTS.md); на
macOS підказки пишуть ⌘ і ⇧.

Текст набирається прямо на полотні в справжньому розмірі: Enter — готово, Shift+Enter — новий
рядок, Esc — скасувати; подвійний клік по напису — редагувати. Вирівнювання й ширина блока — в
інспекторі, обводка тексту йде контуром букв. Shift при відпусканні в накладці знімка кладе знімок
у буфер і бібліотеку й показує в куті екрана плашку: «Редагувати», перетягнути мініатюру в чат чи
теку, зберегти як файл, бібліотека. Експортовані PNG, JPEG і WebP несуть назву, опис, автора,
права, теги й час знімка (без назв вікон і шляхів; вимикається в меню «Інші способи»), а час
файлу дорівнює часу знімка.

Налаштування (шестерня в заголовку) — усередині вікна, кожна зміна застосовується й зберігається
одразу: тека бібліотеки, скільки знімків тримати, автозбереження, метадані, мова, перемикач
гарячих клавіш. На картці бібліотеки при наведенні — перейменувати, показати в теці, у кошик (зі
«Скасувати»; кошик у теці бібліотеки очищується через 30 днів). «Зберегти як…» кладе копію
документа будь-куди; відкрити можна також HEIC, AVIF і TIFF (через кодеки системи; на Windows для
HEIC/AVIF потрібні безкоштовні розширення Microsoft).

```sh
cargo run --release -p znimok-app              # бібліотека
cargo run --release -p znimok-app -- shot.png  # одразу відкрити зображення
```

Бібліотека лежить у `%LOCALAPPDATA%\Znimok\Library` або
`~/Library/Application Support/Znimok/Library`; змінна `ZNIMOK_LIBRARY` задає іншу теку.
Самоперевірка без екрана й миші: `ZNIMOK_SELFTEST=<тека> znimok-app <зображення>` проганяє
сценарій, пише знімки вікна й `report.txt` у теку і повертає код 0, коли всі перевірки пройшли.

## Розробка

- Мова — Rust (edition 2024, stable); робочий простір крейтів — `crates/`.
- Перевірки на кожен push і PR: `cargo fmt --check`, `cargo clippy -D warnings`,
  `cargo test` на Windows і macOS ([.github/workflows/ci.yml](.github/workflows/ci.yml)).
- Задачі ведуться в Jira-проєкті `ZK`. **Кожен коміт, гілка й PR несуть ключ задачі**
  (`ZK-21: …`, гілка `zk-21-workspace`) — так зміни прив'язуються до тікета.
- Основна гілка — `main`; на ній заборонено force-push і видалення.
