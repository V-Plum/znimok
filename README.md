# Znimok

**Українська** · [English](README.en.md)

> **У розробці.** Готових збірок ще немає; код і план змінюються.

Знімки й запис екрана для Windows і macOS з редактором, у якому позначки лишаються
редагованими: стрілку, напис чи приховану ділянку можна поправити й через тиждень.
Знімки й записи лежать у бібліотеці у власному відкритому форматі; результат іде в
буфер обміну, у файл або одразу людині чи агенту.

Znimok — наступник функцій знімків і відео з
[Little Helpers](https://github.com/V-Plum/lilhelpers): той самий досвід, але новий код
на Rust, дві ОС, інсталятор і сучасний інтерфейс. Сумісності з файлами Little Helpers
немає — переноситься функціонал, а не формат.

## Що буде в першій версії

- Знімок екрана, вікна чи ділянки з правильною експозицією в HDR.
- Редактор: рамки, стрілки, текст, лічильники, штампи, маркер, приховування (плашка,
  пікселі, розмиття), кадрування, ефекти; скасування будь-якої дії.
- Бібліотека з мініатюрами, метаданими й пошуком.
- Експорт у PNG/JPEG і поширення; шар команд, CLI і MCP для агентів.

Запис відео з синхронним логом DevTools — у другій версії. Повний план —
[docs/PLAN.md](docs/PLAN.md).

## Спробувати прототип

Перший робочий прототип застосунку — крейт `znimok-app`. Він уміє бібліотеку з мініатюрами й
пошуком, редактор із десятьма інструментами, скасування, автозбереження в бібліотеку,
«Копіювати», експорт у PNG/JPEG/WebP, відкриття файлу, вставку з буфера й перетягування
зображення у вікно. На Windows є «Новий знімок» і Ctrl+Shift+4 (поки весь екран під
курсором). На macOS знімок екрана ще вимкнено.

```sh
cargo run --release -p znimok-app              # бібліотека
cargo run --release -p znimok-app -- shot.png  # одразу відкрити зображення
```

Бібліотека лежить у `%LOCALAPPDATA%\Znimok\Library` або
`~/Library/Application Support/Znimok/Library`; змінна `ZNIMOK_LIBRARY` задає іншу теку.
Самоперевірка без екрана й миші: `ZNIMOK_SELFTEST=<тека> znimok-app <зображення>` проганяє
сценарій, пише знімки вікна й `report.txt` у теку і повертає код 0, коли всі перевірки пройшли.

## Розробка

- Мова — Rust (edition 2024, stable); робочий простір крейтів — `crates/`.
- Перевірки на кожен push і PR: `cargo fmt --check`, `cargo clippy -D warnings`,
  `cargo test` на Windows і macOS ([.github/workflows/ci.yml](.github/workflows/ci.yml)).
- Задачі ведуться в Jira-проєкті `ZK`. **Кожен коміт, гілка й PR несуть ключ задачі**
  (`ZK-21: …`, гілка `zk-21-workspace`) — так зміни прив'язуються до тікета.
- Основна гілка — `main`; на ній заборонено force-push і видалення.
